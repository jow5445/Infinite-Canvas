# Infinite Canvas

![Infinite Canvas](https://user-cdn.hackclub-assets.com/01a0ea14-d63d-755d-a591-9275e7f2c94d/Screenshot%20From%202026-09-29%2000-54-18.png)

A small drawing app where you can draw, move around the canvas, and zoom in or out.

I made this project using plain HTML, CSS, and JavaScript. There are no frameworks or build tools involved.

## Features

* Draw with your mouse or touchscreen
* Change the drawing color
* Change the brush size
* Right-click and drag to move around the canvas
* Scroll to zoom in and out
* Pinch with two fingers to zoom on touch devices
* Clear the whole canvas
* Works on both desktop and mobile

## How to use

Just open `index.html` in your browser.

### Mouse

* **Left click + drag** Draw
* **Right click + drag** Move around the canvas
* **Mouse wheel** Zoom in/out

### Touch

* **One finger** Draw
* **Two fingers** Pan and zoom

## Built with

* HTML
* CSS
* JavaScript
* HTML Canvas API

## Why I made it

I wanted to experiment with the Canvas API and learn how panning and zooming work without using a library.

The drawing data is stored in JavaScript, so the canvas can be redrawn when the user moves or zooms around.

Everything is inside one HTML file to keep the project simple.
